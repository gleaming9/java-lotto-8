# java-lotto-precourse

## 입력
- 로또 구입 금액을 입력받는다.
- 당첨 번호를 입력받는다 (쉼표로 구분)
- 보너스 번호를 입력받는다

## 로직
- 금액에 알맞은 로또들을 발행한다. 로또 번호는 서로 달라야 하며, 오름차순으로 정렬되어야 한다.
- 당첨 내역을 계산한다.
- 총 수익률을 계산한다. (소수점 둘째 자리에서 반올림)

## 출력
- 발행한 로또 수량 및 번호를 출력한다.
- 당첨 내역을 출력한다.
- 총 수익률을 출력한다.
    
## 예외처리
- 로또 구입 금액이 1000원 단위가 아닌 경우
- 당첨 번호 및 보너스 번호가 1~45 사이의 정수가 아닌 경우
- 당첨 번호의 개수가 6개가 아닌 경우
- 당첨 번호와 보너스 번호가 중복될 경우
- 예외 처리 문구는 "[ERROR]" 로 시작해야 한다.
- 사용자가 잘못된 입력을 한 경우, 에러메세지 출력 후 그 부분부터 다시 입력받는다.
