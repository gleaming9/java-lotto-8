# 로또

---
## 기능 구현 목록

### 1) 입력 기능
- [ ] 로또 구입 급액을 입력받는다.
- [ ] 당첨 번호 6개를 쉼표로 구분하여 입력받는다.
- [ ] 보너스 번호 1개를 입력받는다.

### 2) 로또 발행 기능
- [ ] 로또 구입 금액에 해당하는 개수만큼 로또를 발행한다.
- [ ] 로또 번호는 1~45 범위의 중복되지 않는 6개의 정수로 생성한다.
- [ ] 발행된 로또 번호를 오름차순으로 정렬한다.

### 3) 당첨 여부 계산 기능
- [ ] 로또 번호가 당첨 번호와 몇 개 일치하는지 계산한다.
- [ ] 로또 번호에 보너스 번호가 포함되어 있는지 계산한다.

### 4) 당첨 통계 기능
- [ ] 당첨 기준을 Enum으로 관리한다.
- [ ] 구매한 모든 로또를 순회하며 당첨 내역을 집계한다.
- [ ] 총 당첨금을 계산한다.
- [ ] 구입 금액 대비 총 수익률을 계산한다.
  - [ ] 수익률은 소수점 둘째 자리에서 반올림한다.

### 5) 출력 기능
- [ ] 구매 개수를 출력한다.
- [ ] 발행된 로또 번호 목록을 출력한다.
- [ ] 5등부터 1등까지의 당첨 내역을 형식에 맞게 출력한다.
- [ ] 최종 수익률을 출력한다.

### 6) 예외 처리
- 로또 구입 금액
  - [ ] 로또 구입 금액이 1000원 미만인 경우
  - [ ] 로또 구입 금액이 1000원 단위가 아닌 경우
  - [ ] 로또 구입 금액에 문자가 입력된 경우
  - [ ] 로또 구입 금액에 공백이 포함된 경우
---
- 당첨 번호
  - [ ] 당첨 번호가 6개가 아닌 경우
  - [ ] 당첨 번호의 숫자 범위가 1~45 사이의 정수가 아닌 경우
  - [ ] 당첨 번호의 숫자에 중복이 발생할 경우
  - [ ] 당첨 번호에 쉼표가 아닌 문자가 포함된 경우
  - [ ] 당첨 번호에 공백이 포함된 경우
---
- 보너스 번호
  - [ ] 보너스 번호의 숫자 범위가 1~45 사이의 정수가 아닌 경우
  - [ ] 보너스 번호가 당첨 번호와 중복일 경우
  - [ ] 보너스 번호에 문자가 입력된 경우

### 7) 애플리케이션 프름
- 예외 발생 시 [ERROR]로 시작하는 메세지를 출력하고, 해당 입력부터 다시 받는다.
- 예외 발생 시 종료하지 않고 정상적으로 흐름을 이어나간다.
