# java-lotto-precourse

## 기능 구현 목록

## 입력
- 로또 구입 금액을 입력받는다.
- 당첨 번호를 입력 받는다. 번호는 쉽표로 구분한다.
- 보너스 번호를 입력 받는다.

## 핵심 로직
- 금액에 알맞은 로또를 발행한다.
    - 로또 번호는 서로다른 숫자 6자리로 구성되며, 오름차순으로 정렬한다.
- 각 로또들의 당첨 내역을 계산한다.
- 최종 수익률을 계산한다.

## 출력
- 발행한 로또들을 출력한다.
- 각 로또들의 당첨 내역을 출력한다.
- 최종 수익률을 출력한다. 소숫점 둘째자리에서 반올림한다.

## 예외 처리
- 로또 구입 금액이 1000원 단위 양수가 아닌 경우
- 당첨 번호나 보너스 번호가 1 ~ 45 사이가 아닌 경우
- 당첨 번호가 서로 중복될 경우
- 보너스 번호가 당첨 번호와 서로 중복될 경우
